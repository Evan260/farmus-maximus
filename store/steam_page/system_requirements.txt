WINDOWS (required)

Minimum
OS: Windows 10 or 11, 64-bit
Processor: any dual-core processor from the last ten years
Memory: 2 GB RAM
Graphics: any graphics card or integrated graphics supporting OpenGL 3.3
Storage: 200 MB available space

Recommended
Memory: 4 GB RAM
Additional notes: Runs happily in the background while you work.


MACOS (only if the Mac build ships)

Minimum
OS: macOS 11 or later, Apple silicon or Intel
Memory: 2 GB RAM
Graphics: any Mac that runs macOS 11
Storage: 200 MB available space


LINUX / STEAMOS (only if the Linux build ships)

Minimum
OS: a 64-bit distribution from the last five years, or SteamOS
Memory: 2 GB RAM
Graphics: OpenGL 3.3
Storage: 200 MB available space
